# چک‌لیست تست نبض روی آیفون

حدود ۳۰ دقیقه وقت می‌بره. هر جا چیزی عجیب بود، یه اسکرین‌شات بگیر و شماره‌ی همون مرحله رو بنویس.

**آدرس اپ:** https://nasimpourbereimi-dotcom.github.io/nabz/
اگه بدون VPN باز نشد، فقط برای نصب و این تست VPN رو روشن کن.

**فایل‌های آزمایشی** (مصنوعی‌ان، داده‌ی واقعی کسی نیستن):
- export یک‌ساله: https://nasimpourbereimi-dotcom.github.io/nabz/test-data/nabz-sample-export.zip
- متن یه سینک نمونه: https://nasimpourbereimi-dotcom.github.io/nabz/test-data/nabz-sample-sync.txt

---

## ۱. نصب
1. آدرس اپ رو توی **Safari** باز کن (نه Chrome).
2. دکمه‌ی **Share** ← **Add to Home Screen** ← **Add**. (اگه Share رو نمی‌بینی، توی منوی «…» هست.)
3. Safari رو ببند و نبض رو از **Home Screen** باز کن.

**چک کن:**
- [ ] آیکون نارنجی خط نبض و اسم «نبض» زیرش
- [ ] اپ تمام‌صفحه باز میشه، بدون نوار آدرس Safari
- [ ] بالای صفحه زیر ناچ/Dynamic Island نمیره و پایین صفحه روی خط Home نمیفته
- [ ] صفحه‌ی خوشامد نمیگه «اول نبض رو نصب کن» (یعنی اپ فهمیده نصب شده)

## ۲. خواندن export
1. توی Safari، لینک export یک‌ساله رو باز کن ← **Download**. فایل میره توی Files ← Downloads.
2. توی نبض: **شروع کنیم** ← **انتخاب فایل export.zip** ← Files ← Downloads ← فایل رو انتخاب کن.
3. **زمان بگیر** از لحظه‌ی انتخاب فایل تا صفحه‌ی «تاریخچه‌ت رسید».

**چک کن:**
- [ ] نوار پیشرفت و عددها (تمرین، روز، اندازه‌گیری ضربان) جلو میرن
- [ ] کارت «تا اینجا پیدا کردیم» وسط کار ظاهر میشه
- [ ] صفحه‌ی گوشی وسط کار خاموش نمیشه
- [ ] آخرش: ۲۰۵ تمرین و ۳۶۵ روز
- [ ] مدت کل: ……… ثانیه

## ۳. صفحه‌ها
- [ ] **امروز:** چون داده‌ی نمونه مال چند روز پیشه، حلقه‌ی آمادگی باید خاکستری باشه و بنویسه «آخرین عدد آمادگی‌ت، مال …»
- [ ] **تمرین‌ها:** لیست رو تا پایین اسکرول کن، یه تمرین رو باز کن، بعد با **کشیدن انگشت از لبه‌ی چپ صفحه** برگرد. باید سر همون جای لیست برگردی.
- [ ] **جزئیات تمرین:** نمودار ریتم، زون‌ها، «چی فهمیدیم». یه عدد برای «چقدر سخت بود؟» بزن.
- [ ] **روندها:** انگشتت رو روی یه نمودار بکش؛ بالای نمودار باید تاریخ و عددها عوض بشن. بازه رو بین «۳ ماه» و «همه» عوض کن.
- [ ] **Wrapped:** همه‌ی کارت‌ها رو با «بعدی» ببین. روی یکی دکمه‌ی اشتراک رو بزن ← **Save Image** ← توی Photos نگاهش کن: باید عین کارت باشه و فونت فارسی درست باشه.
- [ ] کلاً: کندی یا پرش موقع اسکرول؟ متنی که بیرون زده یا روی هم افتاده؟

## ۴. آفلاین
1. اپ رو کامل ببند (از پایین صفحه بکش بالا و نبض رو بنداز بیرون).
2. **حالت هواپیما** رو روشن کن (Wi-Fi هم خاموش).
3. نبض رو از Home Screen باز کن.

- [ ] اپ باز میشه و همه‌ی داده‌ها و نمودارها سر جاشونن
- [ ] فونت فارسی درسته (فونت از خود اپ میاد، نه اینترنت)

حالت هواپیما رو خاموش کن.

## ۵. سینک (بدون Shortcut)
1. توی Safari لینک «متن یه سینک نمونه» رو باز کن، کل متن رو انتخاب کن (**Select All**) و **Copy** کن.
2. توی نبض، صفحه‌ی امروز، دکمه‌ی **سینک** رو بزن. چون Shortcut هنوز ساخته نشده، Shortcuts احتمالاً میگه پیداش نکرده؛ برگرد به نبض.
3. **چسباندن داده‌ها** رو بزن ← توی پیام iOS **Paste** (یا Allow Paste) رو بزن.

- [ ] پیام «سینک شد · ۱ تمرین تازه · …» میاد
- [ ] حالا صفحه‌ی امروز حلقه‌ی رنگی داره (داده‌ی امروز رسیده) و چراغ کنار سینک پر شده
  (متن نمونه مال ۲ آذر ۱۴۰۵ ـه. اگه این تست رو از ۴ آذر به بعد انجام بدی، حلقه خاکستری می‌مونه و این طبیعیه.)
- [ ] تمرین تازه توی لیست هست و ازت می‌پرسه «تمرین قدرتی بود؟»
- [ ] اگه Paste کار نکرد: «دستی بچسبون» رو امتحان کن و بنویس چی شد

## ۶. تنظیمات و بک‌آپ
آیکون استوانه‌ای بالای صفحه‌ی امروز.
- [ ] «ذخیره‌سازی» چی نوشته: **ماندگار** یا **موقت**؟
- [ ] **گرفتن بک‌آپ** ← توی Share Sheet ← **Save to Files** ← یه جا ذخیره کن
- [ ] **بازگردانی از بک‌آپ** ← همون فایل رو انتخاب کن ← بعدش همه‌چیز باید مثل قبل باشه
- [ ] **راهنمای ساخت Shortcutها** باز میشه (حتی با حالت هواپیما)
- [ ] اگه بخش **گزارش فنی** دیده میشه، یعنی خطایی ثبت شده: **کپی گزارش** رو بزن و متنش رو بفرست

## ۷. (اختیاری ولی خیلی مفید) export واقعی خودت
داده‌ی واقعی فقط روی گوشی خودت می‌مونه. فقط بدون که چون هنوز آدرس نهایی (دامنه‌ی .ir) رو نداریم،
بعداً روی آدرس جدید یه بار دیگه باید import کنی.
1. اپ Health ← عکس پروفایل ← **Export All Health Data** (ممکنه چند دقیقه طول بکشه) ← **Save to Files**
2. توی نبض: تنظیمات ← **خواندن export.zip تازه** ← فایل رو انتخاب کن

- [ ] حجم فایل zip: ……… مگابایت
- [ ] مدت import: ……… دقیقه
- [ ] اپ وسط کار بسته شد یا گیر کرد؟
- [ ] عددها (تعداد تمرین، نوع تمرین‌ها، خواب، ضربان استراحت) با چیزی که توی Health می‌بینی جور درمیان؟
